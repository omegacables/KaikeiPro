# Raqto会計（AIバージョン）- 機能一覧

最終更新: 2026-06-09

---

## 凡例

| 記号 | 意味 |
|------|------|
| **実装済** | DB連携・CRUD動作する |
| **UI のみ** | 画面はあるがバックエンド未接続 |
| **未実装** | ページ/機能が存在しない |

---

## 1. 認証・ユーザー管理

| 機能 | 状態 | 説明 |
|------|------|------|
| メールログイン | 実装済 | Supabase Auth によるメール/パスワード認証 |
| ロール判定 | 実装済 | super_admin / admin / staff / client の4ロール自動判定 |
| ルート保護 | 実装済 | middleware でログイン必須。未認証時はログイン画面へリダイレクト |
| セルフサービスアカウント作成 | 実装済 | 顧問先が自分で会計を始められるモード |
| 顧問先ポータルアカウント作成 | 実装済 | スタッフが顧問先用のログインアカウントを発行 |
| 事務所メンバーアカウント作成 | 実装済 | 管理者がスタッフアカウントを発行 |
| 二要素認証 | UI のみ | 設定画面にUIはあるが動作しない |
| セッション管理 | UI のみ | 設定画面にUIはあるが動作しない |
| パスワード変更 | UI のみ | 「準備中」表示 |

## 2. ダッシュボード

| 機能 | 状態 | 説明 |
|------|------|------|
| スーパー管理者ダッシュボード | 実装済 | 全事務所・全顧問先の一覧。事務所の新規作成 |
| スタッフダッシュボード | 実装済 | 要確認の証憑・税務カレンダー・請求書状況（未入金/期限超過）・支払状況（未払/期限超過）・残高サマリーの5ウィジェットを横3列で表示 |
| 残高サマリーウィジェット | 実装済 | 顧問先セレクタ付き。口座残高（現金・預金）＋補助科目別残高を集計（`getBalanceSummary`）。マイナス残は絶対値＋「貸方残/借方残」タグで表示（帳簿マイナス非表示ルール準拠） |
| 請求書状況／支払状況ウィジェット | 実装済 | 顧問先別の未入金・期限超過を集計（`getInvoiceStatusByClient`/`getPayableStatusByClient`）。クリックで該当請求書一覧へ遷移 |
| 顧問先ダッシュボード | 実装済 | 未処理レシート数・AI仕訳レビュー数・未回答質問数。業務メニュー。ポータルアカウント管理 |
| ウィジェットカスタマイズ | 実装済 | ドラッグ不要のトグルで表示/非表示を切替。localStorage に保存 |

## 6. 領収書

| 機能 | 状態 | 説明 |
|------|------|------|
| 領収書一覧 | 実装済 | ステータス別タブ。グリッド/リスト切替。検索 |
| 領収書登録 | 実装済 | 取引先・日付・金額・支払方法・メモ |
| ステータスフロー | 実装済 | アップロード済 → 処理中 → OCR完了 → レビュー済 → 仕訳化済 |
| 画像アップロード | 実装済 | Supabase Storage `receipts` バケットへアップロード（`receipt-storage.ts`、SHA-256重複検出・署名付きURL）。仕訳入力ではモバイルのカメラ撮影にも対応 |
| AI-OCR | 実装済 | Gemini 2.5 Pro Vision で日付・金額・税額・取引先名・インボイス番号等を抽出（`actions/ocr.ts`）。結果は ocr_result に保持し画面で修正可 |
| AI仕訳自動生成 | 実装済 | OCR結果から Gemini 2.5 Flash が勘定科目を推定し下書き仕訳を自動作成（`actions/ai-journal.ts`）。発行/受領で売上仕訳・経費仕訳を出し分け |
| 証憑フォルダ管理 | 実装済 | 証憑をフォルダで整理（`receipt-folders.ts`、`/documents`） |

### カード取引（`actions/cards.ts` / `/card-transactions`）
