# Raqto会計（AIバージョン）- 機能一覧

最終更新: 2026-02-22

---

## 凡例

| 記号 | 意味 |
|------|------|
| **実装済** | DB連携・CRUD動作する |
| **UI のみ** | 画面はあるがバックエンド未接続 |
| **未実装** | ページ/機能が存在しない |

---

## 1. 認証・ユーザー管理

| 機能 | 状態 | 説明 |
|------|------|------|
| メールログイン | 実装済 | Supabase Auth によるメール/パスワード認証 |
| ロール判定 | 実装済 | super_admin / admin / staff / client の4ロール自動判定 |
| ルート保護 | 実装済 | middleware でログイン必須。未認証時はログイン画面へリダイレクト |
| セルフサービスアカウント作成 | 実装済 | 顧問先が自分で会計を始められるモード |
| 顧問先ポータルアカウント作成 | 実装済 | スタッフが顧問先用のログインアカウントを発行 |
| 事務所メンバーアカウント作成 | 実装済 | 管理者がスタッフアカウントを発行 |
| 二要素認証 | UI のみ | 設定画面にUIはあるが動作しない |
| セッション管理 | UI のみ | 設定画面にUIはあるが動作しない |
| パスワード変更 | UI のみ | 「準備中」表示 |

## 2. ダッシュボード

| ウィジェットカスタマイズ | 実装済 | ドラッグ不要のトグルで表示/非表示を切替。localStorage に保存 |
